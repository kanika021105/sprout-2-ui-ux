# Sprout 2.0 — UI/UX Design Assignment

## Project Overview
Sprout 2.0 is a conceptual, mobile-first investing experience designed to make onboarding simpler, clearer, and more approachable for first-time investors in India.

## Objectives
- Simplify the first-time investor onboarding journey.
- Communicate KYC requirements in a clear and understandable way.
- Build user trust through transparent communication.
- Prioritize mobile accessibility and usability.
- Help users understand investment risks before getting started.

## Design Deliverables
- Mobile homepage
- Five onboarding screens
- Visual style guide and UI components
- Mascot concepts
- Figma design and prototype
- UI/UX case study PDF

## Tools Used
- Figma — UI/UX design and prototyping
- Git — version control
- GitHub — project documentation and submission

The case study PDF included in this repository documents the project concept, user journey, visual design system, accessibility considerations, and proposed usability improvements.

## Project Status
This is a conceptual UI/UX design project. It is not a live investment service, and no actual investment transactions are processed through this design.
