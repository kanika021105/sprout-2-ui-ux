# Sprout 2.0 — UI/UX Design Assignment

## Project Overview
Sprout 2.0 is a conceptual mobile-first investing experience designed to make onboarding easier for first-time investors in India.

## Objectives
- Simplify the onboarding journey.
- Explain KYC requirements clearly.
- Build trust through transparent communication.
- Prioritize mobile accessibility and usability.

## Deliverables
- Mobile homepage
- Five onboarding screens
- Visual style guide and UI components
- Mascot concepts
- Clickable Figma prototype
- UI/UX case study
